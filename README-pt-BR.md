<h1>📂 Dotfiles</h1>
Configurações personalizadas para ambientes como <b>Arch Linux</b>, <b>Debian</b>, <b>Ubuntu</b>, <b>Termux</b> e <b>outros</b>. As configurações incluem arquivos como <b>.bashrc</b>, <b>.bash_aliases</b>, e <b>outras personalizações</b>.

<b>Cada pasta é nomeada de acordo com o sistema operacional correspondente.<b>
</pre>

cd dotfiles
